# 验证范围

本仓库提供 Windows / Python 3.11+ 标准库环境的验证流程。本文说明覆盖范围，
不承诺当前候选已通过；每次发行以实际运行记录为准。tests/acceptance.py 将环境与结果
写入本地 .qa/acceptance.json，该目录不随公开包发布。对外可另附脱敏结果与 ZIP 摘要。

测试覆盖：默认与最简模式、预览无写入、恢复记录、正常编辑、私人配置严格格式与大小限制、
私有导出再导入、导出限定两份文件且不输出正文、未管理/修改/私人文件在退出时保留、
非空目标拒绝、旧版本状态拒绝、路径和状态篡改、硬链接及真实 Windows junction、
写入失败清理、Windows 保留设备名/设备命名空间/ADS/尾点空格在访问前拒绝、
非普通文件在读取前拒绝。设备与管道用 mock 检查，不实际访问。

发行验收从 ZIP 解压后运行同一测试集以及命令行生命周期，并检验重复构建字节一致、
精确允许清单外文件阻止打包，并补充扫描已知本机身份/路径/凭据标记；扫描不是完整秘密检测。
源码发布另需按 docs/release.md 在干净 Git 检出验证换行和构建摘要，现有 acceptance
不自动完成这一步。独立审查、额外探针及新机实测如有执行，应单独记录，不从本文推定通过。

这些检查不能证明新电脑的助手自动加载规则、真实用户收益、其他操作系统、语义正确性，
也不保证并发恶意文件修改或断电事务原子性。私人文本不做完整秘密检测，
传递前需本人检查。demo 状态更新失败可能保留未登记示例输出；卸载 IO 失败后需要检查现场。
本版无原位升级器，也没有将原私人包全部工具迁入公共核心。

已验证基线、当前 RC 的交付附件与 Windows/Linux CI 状态分开记录，见 [公开验证说明](VALIDATION.md)。
工作流存在不表示已经在远端通过；非 Windows 环境会跳过 Windows junction 专用用例。
