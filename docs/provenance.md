# 来源与公开分发边界

这一版本由先前的通用 Starter 向统一核心演进。程序、模板与文档在本项目实现；方法来自作者已实践的用户级协作规范、分析视角、任务编排和备份恢复约定，并结合旧 Starter 的行为边界重新组织。它不是所有理念均为原创的声明，也不是把私人文件改名后公开。

| 公开资产 | 来源类别与处理 |
| --- | --- |
| 本地 CLI、测试、发布构建 | 延续通用 Starter 实现，增加推荐/最简预设与私人配置迁移；合成样例不代表真实任务效果 |
| 默认协作风格 | 从已确认表达、证据、独立判断等实践改写；去掉职业、个人身份、历史来源细节和授权 |
| 分析视角小索引 | 根据证据判断、基本机制、当前版本、方案取舍、责任、可行动呈现等方法重新摘要 |
| 任务执行与续接 SOP | 参考用户级执行与模型路由规范；去掉特定模型、强制派发和本机路径 |
| 资料归位 SOP | 参考固定主题、唯一主版本、临时与交付副本分离、归位验收的实践 |
| 研究与证据 SOP | 参考来源核验、事实与推断区分、文档声明与实测区分的协作规范 |
| 变更与恢复 SOP | 参考备份恢复、最小影响验证、消费者核对与冲突拒绝覆盖的实践 |
| 工具采用 SOP | 参考来源、许可、依赖、真实调用与权限边界；不继承作者历史安装授权 |
| 收尾沉淀 SOP | 参考已有方法优先、候选先验证、唯一状态与归档检查；不复制特定工作区固定回执 |
| 空白私人配置与首次说明 | 新编写的通用入口；使用者自行决定提供哪些偏好或背景 |

## 私人资产的处理

| 资产类别 | 决定 |
| --- | --- |
| 通用协作原则、可复用方法、最低充分 SOP | 通过上表改写纳入公开核心 |
| 本人的已确认画像、偏好、私人路径 | 留在私人配置或本人资料区，不进入公开核心 |
| 不在本公开清单中的工具、工作区脚本和模板 | 不随包分发；需单独核对来源、许可、依赖和适配范围 |
| 公司、客户、业务项目正文和正式台账 | 不纳入 |
| 对话、日志、统计、密钥、认证、缓存、自动化状态 | 不纳入 |
| 第三方 Skills、插件代码及模板库 | 不随本版本分发；未来复用先核对固定版本、许可与归属 |
| Python 和系统运行环境 | 外部前提，不打包 |

没有读取或复制公司项目正文来编写这些公开 SOP。未打包第三方 Skill 代码；参考实践与软件再分发是不同事项。

公开构建以精确允许清单决定范围，扫描仅作补充，不能代替来源与发布授权。私人配置导出是给本人迁移使用，不是公开发布物；相邻哈希只能核对内容一致性，不能证明发布者身份。不要将本人私人导出加入公开仓库或公开 release。

本项目代码、公开模板及文档沿用 [MIT](../LICENSE)，归属 Harness Starter contributors。第三方权利不由该许可证覆盖。本地构建不等于已经发布到 GitHub。
