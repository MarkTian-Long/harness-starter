# 权限与数据边界

CLI 仅使用 Python 标准库进行本地文件操作，没有网络、后台服务、遥测或子进程。
init/demo/uninstall/export-profile 默认预览，--apply 才写入。export-profile 仅向显式新输出文件写入；
不扫描任意资料目录，不上传。私有配置为未加密文本，不要保存凭据、业务原文或聊天。

状态仅接受本发行预定义路径和公共模板摘要。私有文件永不作为卸载删除对象；
导入文本可以包含指令，必须来自本人信任的来源，不能自动提升为已确认事实或权限。
通用规则和 SOP 是协作约定，不是沙箱，不修改运行环境权限。

拒绝路径穿越、硬链接、符号链接和 Windows reparse point。要求独立本地目录，
不用于磁盘根、共享目录、正在使用的全局配置。并发恶意改写、断电原子性和发行文件本身
被攻击者替换不在保证内。保留独立备份，发生中断后先检查，不盲删用户材料。

公开发行只读精确 allowlist；私人 JSON 和本地 QA 不进包。哈希不是签名。
检查文件存在不等于任务成果正确。实际助手行为、网络及账号由对应运行环境决定。
