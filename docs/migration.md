# 从已有目录迁移到公共核心

第一次使用只需要公共源码或发行 ZIP，不需要其他私人包、账号或工具集合。
本包在专用空目录中初始化，不提供原位升级或整机迁移。

## 可带入什么

| 已有内容 | 在本包中的处理 | 边界 |
| --- | --- | --- |
| 自己的表达偏好和愿意提供的背景 | 自行填写 `private/overlay.md`、可选 `private/profile.md`，或明确指定受支持的私人 JSON | 只处理这两份文本，不继承历史授权 |
| 项目规则、资料、成果和任务状态 | 在所属项目的正式入口继续维护，按需引用 | 不为了迁移批量移动业务资料 |
| 已有方法或工具 | 保留其主源，按当前任务核对来源、依赖、许可与实际调用 | 不随初始化或私人配置导入自动安装 |
| 旧任务检查点 | 核对进度、来源和当前完成条件后续接 | 不从模板推定任务已经完成 |
| 聊天、账号、凭据、后台服务或机器配置 | 由其原系统管理 | 本包不读取、导出或迁移 |

私人 JSON 是未加密的数据快照。迁移前本人审阅正文，使用可信渠道传递；不要提交到公开仓库或公开发行附件。
接收时重新核对事实、路径、账号、依赖和授权。文件导入成功不证明新环境工具可用或助手已读取规则。

## 已用旧 Starter 的使用者

旧版本状态需由匹配的旧脚本检查和退出。新版本拒绝不匹配的状态，不盲目覆盖。
保留旧目录、原脚本和原发行，在新空目录试用当前版本；需要时审阅自己的偏好后填入新私人层。
项目材料继续在原正式位置维护，旧配置与新配置不平行手改为两份主源。

## 升级与回退

本版没有原位升级器。退出保留私人内容、用户修改和未登记文件。
回退继续使用保留的旧目录、匹配脚本与原发行；`rollback` 命令本身只是卸载别名。
本包不撤销外部工具安装、账户连接或助手设置，也不会自动同步多个环境。
