# 一套核心，两种起点，私人配置单独保存

推荐模式 recommended 默认安装作者协作风格、按需 SOP 和续接检查点。minimal 保留基础任务文件与首次使用说明，适合短任务或已有成熟流程。它们使用同一个程序和格式，不是两套产品。

| 组成 | 推荐模式 | 最简模式 | 实际用途 |
| --- | --- | --- | --- |
| AGENTS.md、FIRST_USE.md、task.md | 有 | 有 | 开始任务、明确输入和完成条件 |
| workspace/、personal/ | 有 | 有 | 项目材料与独立实验分开 |
| private/overlay.md | 空白 | 空白 | 使用者填写个人偏好 |
| profile/style.md | 有 | 无 | 作者协作风格和六类分析视角 |
| standards/ 六份 SOP | 有，按需读 | 无 | 执行续接、归位、证据、变更恢复、工具采用、收尾 |
| recovery/checkpoint.md | 默认有 | 可用 --recovery 添加 | 中断时留下可继续的状态 |
| 私人配置导入/导出 | 同一命令支持 | 同一命令支持 | 迁移本人偏好与自填画像，不进入公开 ZIP |
| 第三方 Skills、账户、运行时依赖 | 不随包提供 | 不随包提供 | 另按需评估和验证 |
| 自动维护服务、自动安装、全局注入 | 不提供 | 不提供 | 不会因为初始化而后台运行 |

private/profile.md 可自行建立，装入本人背景与适用范围。导入导出只处理受支持的私人配置文件，并不是复制旧私人迁移包的全部资产；不会搬业务项目、对话、工具安装、账号或旧授权。实际文件范围以命令预览为准。

作者风格是可编辑默认值，不是使用者的已确认画像。默认程序检查只判断文件和安装状态，无法保证助手服从规则、研究正确或任务完成。相同文件编辑后仍可用并不代表内容经过验证。

每次任务仅按触发读取必要 SOP。没有收益时使用最简模式，不为“完整体系”制造台账。init 不承担旧目录升级；比较模式请用另一空目录，现有改动自行保留。卸载保留私人文件以及修改过或未管理的文件，不保证留下完全空目录。
