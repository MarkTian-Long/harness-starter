# 任务执行与续接

适用：多步、跨对话任务或交接。短问答不要求建档。

1. 确认目标、权威输入、范围和可观察完成条件；优先更新已有任务入口，没有时使用 task.md。
2. 定位最小必要材料、当前权威源及直接相关的已有方法，先复用适用的 SOP、Skill、模板或脚本；有真实缺口才依工具采用 SOP 取新小件。核对当前状态，事实、候选、未确认分开；链接存在或旧摘要不证明已经读用。
3. 按依赖推进。机械核对用工具；只有子问题独立、可验证、写入范围清楚且运行环境允许时才委派。共用状态由协调方合并，未实际派发不声称并行。
4. 完成已授权实施和必要验证；新信息改变目标或权限时停在具体边界，说明推荐与影响。
5. 中断前在唯一状态处写已有成果与位置、实际验证、剩余事项、下一安全动作、等待谁提供什么。已有状态足够时不另建副本。
6. 续接先检查事实与文件是否变化，再继续未完成部分。本地试验不等于上线或用户验收。

最小记录可用：目标／当前结果／证据位置／下一步／真实阻塞。记录服务续接，不追求流水账。
