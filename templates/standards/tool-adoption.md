# 可复用小件与外部能力采用

适用：按真实任务定位和取用 SOP、模板、图样、脚本、Skill，或评估、安装、连接和替换工具、插件、自动化。

1. 先按任务对象查现有正式入口和已采用主源，读取适用正文；能解决就复用，不为“新”再建同义方法。存在真实缺口时比较单项收益、替代和维护成本，不因可安装而批量接入。
2. 核对来源、固定版本/提交、许可证、数据去向、依赖与影响范围。集合仓库的 main 用于导航，实际取用固定快照；保留所选小件的必要资源与说明，不整包安装。SOP 可直接读，脚本或 Skill 的依赖和宿主支持按其说明单独核验。
3. 判断当前任务是否授权动作。安装、账号连接、扩权、外部写入、无人值守是不同边界；风格预设与旧用户授权不授予这些权限。
4. 范围和授权清楚后，优先隔离环境、非敏感样本，完成所选小件的最小实际使用。只阅读、下载、被发现或完成配置，不能称为实际调用或任务成功；受控合成使用不等于独立真实收益。
5. 分开观察找到、用对、具体帮助和额外负担。根据真实消费者与失败样本决定保留、缩小范围、合并、仅显式调用、停用或移除；在已有任务或依赖说明记录固定来源、实际使用、恢复与下一复核触发，不另建注册表。通用改动回唯一编辑源，再生成发布或安装快照。复用已有手动审计与实际使用结论，只补本次可移植性、许可和发布范围；静态发布检查不作长期收益证据，不另建有效性评分，发布后的新事实回原记录。
6. 版本、权限、数据流改变后复核。公开再分发独立核对许可；核心不默认下载第三方工具，不复制认证状态。

能力可调用不等于有权调用；配置成功不等于任务成功。
